# Sobre Mim
Olá! Sou Pablo Henrique, graduando em Engenharia de Software (7/8). Atuo como desenvolvedor Full-Stack com foco principalmente no ecossistema React e Java, construindo aplicações modernas, escaláveis e de alta performance. Gosto de transitar por todo o ciclo do software, desde a estruturação de bancos de dados e APIs robustas no Back-end até a criação de interfaces dinâmicas no Front-end.
